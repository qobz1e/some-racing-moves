# Incremental Racing — Unity Prototype

## Требования
- Unity 2022.3 LTS или новее  
- Package: **TextMeshPro** (встроен, просто подтвердить импорт при первом запуске)

---

## Быстрый старт (3 шага)

### 1. Создай проект
- File → New Project → **2D (Built-In Render Pipeline)**
- Назови `RacingPrototype`

### 2. Скопируй скрипты
Скопируй все `.cs` файлы из папки `Assets/Scripts/` этого архива в папку  
`Assets/Scripts/` своего проекта.

Скрипты:
```
TrackData.cs          — данные трассы (вейпойнты)
TrackRenderer.cs      — рисует трассу через LineRenderer
CarController.cs      — (вспомогательный, не используется напрямую)
CarTrackBridge.cs     — связывает машину с трассой + CarController2
EconomyManager.cs     — монетки за круг
HUDController.cs      — HUD: монеты, скорость, лап-каунтер
SceneBootstrap.cs     — автоматически строит всю сцену при запуске
```

### 3. Настрой сцену
1. Открой пустую сцену (или создай новую: File → New Scene → Basic 2D)
2. Создай пустой GameObject: **правая кнопка в Hierarchy → Create Empty**
3. Назови его `SceneBootstrap`
4. Добавь компонент `SceneBootstrap` (Add Component → поиск "SceneBootstrap")
5. **Нажми Play ▶**

Всё остальное создаётся автоматически.

---

## Управление

| Платформа | Действие |
|-----------|----------|
| PC / Editor | **Зажать Space** или **зажать ЛКМ** → ускорение |
| Mobile | **Любой тап** → ускорение |

Отпустить = машина замедляется и останавливается.

---

## Что происходит в игре

1. Машина стоит на старте (жёлтая финишная черта — верхний левый угол трассы)
2. При первом нажатии начинает двигаться по прямоугольной трассе
3. **Speed bar** внизу экрана показывает текущую скорость (0–max)
4. После каждого полного круга:
   - **Lap** счётчик увеличивается
   - Начисляется **+10 монет** (жёлтый попап в центре)
   - Баланс обновляется в верхнем левом углу

---

## Параметры для балансировки (Inspector → CarTrackBridge → CarController2)

> После первого запуска найди объект **Car** в Hierarchy, там будет `CarController2`

| Параметр | Default | Описание |
|----------|---------|----------|
| `maxSpeed` | 8 | Максимальная скорость (юнитов/с) |
| `acceleration` | 18 | Прирост скорости при тапе (юнитов/с²) |
| `deceleration` | 6 | Падение скорости без тапа (юнитов/с²) |

`EconomyManager` → `coinsPerLap` — монеты за круг (default 10).

---

## Структура кода (для расширения)

```
CarController2.OnLapCompleted  →  EconomyManager (начисляет монеты)
                               →  HUDController  (обновляет Lap)
EconomyManager.OnCoinsChanged  →  HUDController  (обновляет монеты + попап)
```

Все зависимости через **C# events** (`System.Action`) — никаких прямых ссылок между менеджерами.
